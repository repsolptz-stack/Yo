# НоНарко | ПТЗ — PWA-приложение для публикации на GitHub Pages

Готовые файлы для вашего репозитория (`repsolptz-stack.github.io/Yo/`):

1. `index.html` — мобильное приложение в стиле кабинета в Петрозаводске (песочная база, патинированный бирюзово-охристый градиент, древесные акценты, экспресс-оценка для близких, конструктор заявки для Telegram и ВКонтакте, контакты с прямыми ссылками на звонки и Яндекс.Карты, кнопка быстрого выхода).
2. `manifest.json` — манифест веб-приложения для установки на экран смартфона (Android / iOS).
3. `sw.js` — Service Worker для кэширования и доступа к контактам и памяткам в офлайн-режиме.

## Как загрузить с телефона на GitHub

1. Откройте ваш репозиторий на GitHub в мобильном браузере.
2. Загрузите или замените файлы `index.html`, `manifest.json` и `sw.js` в корневой папке репозитория.
3. Дождитесь обновления GitHub Pages (обычно 1–2 минуты) и откройте страницу — появится возможность установить приложение на главный экран.
